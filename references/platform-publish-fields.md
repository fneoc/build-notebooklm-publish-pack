# Platform Publish Fields

Use this reference when creating platform-specific publish-info text files. Keep each platform in a separate file.

## Chinese Short Video

Useful for 视频号, 抖音, 快手, and similar Chinese short-video channels.

Include:

1. Short title.
2. Video description.
3. Hashtags.
4. Upload filenames for MP4 and cover/image.
5. Location, collection, link, activity, and scheduling fields only if useful.

Style:

- Lead with the concrete topic, not the tool.
- Keep hashtags compact.
- Mention NotebookLM/Codex only when the user wants tool disclosure.

## BILIBILI

Include:

1. Title.
2. Intro/description.
3. Tags.
4. Partition/category suggestion.
5. Upload filenames.
6. Cover image filename.

Style:

- Slightly more explanatory than short-video copy.
- Add source/provenance notes when the package is news, research, or education.

## TikTok / YouTube Shorts

Include:

1. English hook title.
2. Caption.
3. Hashtags.
4. Upload filename.
5. Cover filename if available.

Style:

- Write for a global audience.
- Prefer one clear takeaway over a dense summary.
- Avoid literal translation from Chinese if the audience context differs.

## Xiaohongshu

Include:

1. Note title.
2. Body copy with skim-friendly line breaks.
3. Hashtags.
4. Image/video filenames.

Style:

- More personal and practical.
- Make images central; mention what viewers can learn from the visual.

## LinkedIn

Include:

1. Professional headline.
2. 2-4 paragraph post body.
3. Source/provenance line.
4. Asset filenames.

Style:

- Focus on implications and decisions.
- Use fewer hashtags.

## Long Reports

Useful for 3,000+ word reports, research essays, white papers, and field-study articles.

Create separate copy for:

1. Short-video hook: 1 clear tension, 1 practical takeaway, concise hashtags, video and cover filenames.
2. Deep-summary post: 3-6 key arguments, source/provenance line, and a prompt for readers to watch or read the full package.
3. Long-form article: structured title, abstract, sectioned notes, source link, and image filenames when the platform supports them.

Recommended channels:

- 公众号 or long-form Chinese article: use a report-style headline, a short abstract, section headings, and the source/provenance note.
- BILIBILI column or video description: include a longer intro, chapter-like bullet points, tags, and cover filename.
- LinkedIn: write for professional implications and management decisions, not a literal translation.
- Xiaohongshu: make the practical checklist or visual takeaways central.

Style:

- Do not compress a long report into only a news caption.
- Separate "what happened", "why it matters", and "what to do next".
- Keep the short-video copy punchy, but keep the deep-summary copy faithful to the report's structure.

## Quality Checks

1. Platform copy should name the actual content topic.
2. Upload filenames should match files on disk.
3. Chinese and English copy should be separately written for each audience.
4. Do not include publishing settings the user did not ask to control unless they are part of an existing template.
