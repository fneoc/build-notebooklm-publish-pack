# Examples

This directory contains lightweight, public-friendly case studies for `build-notebooklm-publish-pack`.

The examples focus on process evidence rather than heavyweight assets. Full raw sources, generated MP4 files, and full-size image downloads are usually omitted to keep the repository small and avoid republishing third-party content.

## Cases

- [睡前消息【2026-6-4】高考怕 KTV](sleep-message-20260604-ktv/README.md): a pasted Markdown news digest turned into a bilingual NotebookLM publishing package with Chinese video, English video, official infographic, platform copy, and strict audit evidence.
